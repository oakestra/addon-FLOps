**FLOps** is an [Oakestra](https://github.com/oakestra/oakestra) [Addon](https://www.oakestra.io/docs/concepts/oakestra-extensions/addons/) that enables streamlined and accelerated practical Federated Learning workflows through many of its automation features.

📚 Check out the [FLOps **Wiki**](https://www.oakestra.io/docs/concepts/flops/overview/#flops-addon) to get started.

## 📕 Requirements 
- Linux (preferably Debian/Ubuntu)
- Python Version **3.10+**
